COMO TRANSFORMAR O CARD EM UM CARROSSEL INFINITO E RESPONSIVO
============================================================

1. ESTRUTURA HTML (teste.html)
-------------------------------
O card atual (linha 12-66) sera envolvido por um container Swiper.
Estrutura necessaria:

<div class="swiper slider-wrapper">
  <div class="swiper-wrapper">
    <!-- Repetir o bloco .card N vezes (minimo 3-4 para efeito infinito) -->
    <div class="swiper-slide">
      <div class="card">...</div>
    </div>
    <div class="swiper-slide">
      <div class="card">...</div>
    </div>
    <div class="swiper-slide">
      <div class="card">...</div>
    </div>
  </div>
  <!-- Pagination (bolinhas) -->
  <div class="swiper-pagination"></div>
  <!-- Setas de navegacao -->
  <div class="swiper-button-prev"></div>
  <div class="swiper-button-next"></div>
</div>

IMPORTANTE: O Swiper precisa de no minimo 3 slides para o loop
funcionar corretamente. Cada card vira um <div class="swiper-slide">
que envolve o <div class="card">.

Adicionar o CDN do Swiper no <head>:
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/swiper@11/swiper-bundle.min.css">
<script src="https://cdn.jsdelivr.net/npm/swiper@11/swiper-bundle.min.js"></script>


2. ESTILOS CSS (estilos/style.css)
------------------------------------
Adicionar os estilos do Swiper e adaptar o card:

/* Container do carrossel */

  width: 100%;
  max-width: 1200px;
  margin: 0 auto;
  padding: 20px 0;
}

/* Cada slide */
.swiper-slide {
  display: flex;
  justify-content: center;
  align-items: center;
  height: auto;
}

/* O card dentro do slide deve se adaptar */
.swiper-slide .card {
  width: 100%;
  max-width: 280px;
  margin: 0 auto;
}

/* Pagination bullets */
.swiper-pagination-bullet {
  background: rgba(255, 255, 255, 0.5);
}
.swiper-pagination-bullet-active {
  background: #049fbb;
}

/* Setas de navegacao */
.swiper-button-prev,
.swiper-button-next {
  color: #049fbb;
}

/* Responsividade via breakpoints do proprio Swiper (no JS) +
   CSS auxiliar: */
@media (max-width: 768px) {
  .swiper-slide .card {
    max-width: 240px;
  }
  .swiper-button-prev,
  .swiper-button-next {
    display: none; /* esconde setas no mobile */
  }
}

@media (min-width: 769px) {
  .swiper-pagination {
    display: none; /* esconde bolinhas no desktop */
  }
}


3. JAVASCRIPT (js/script.js)
-------------------------------
O script ja esta configurado. Manter/ajustar assim:

const swiper = new Swiper('.slider-wrapper', {
  loop: true,                  // Loop infinito
  grabCursor: true,
  spaceBetween: 30,
  pagination: {
    el: '.swiper-pagination',
    clickable: true,
    dynamicBullets: true
  },
  navigation: {
    nextEl: '.swiper-button-next',
    prevEl: '.swiper-button-prev',
  },
  breakpoints: {
    0: {
      slidesPerView: 1          // 1 card no mobile
    },
    768: {
      slidesPerView: 2          // 2 cards no tablet
    },
    1024: {
      slidesPerView: 3          // 3 cards no desktop
    }
  },
  autoplay: {
    delay: 3000,                // Avanca a cada 3s
    disableOnInteraction: false // Continua mesmo apos interacao
  }
});

OBSERVACAO: Adicionar "autoplay" torna o carrossel rolar
automaticamente sem precisar de clique/seta.


4. PASSOS RESUMIDOS
---------------------
a) Adicionar CDN do Swiper (CSS + JS) no <head> de teste.html
b) Envolver os cards com .swiper > .swiper-wrapper > .swiper-slide
c) Duplicar o card no minimo 3 vezes dentro de .swiper-wrapper
d) Adicionar divs de pagination e navigation apos .swiper-wrapper
e) No CSS, estilizar .slider-wrapper, .swiper-slide e pagination
f) No JS, manter a configuracao com loop: true e adicionar autoplay
g) Testar responsividade nos breakpoints 0, 768 e 1024px

3. JAVASCRIPT (js/script.js)
------------------------------------
Adicionar apos o Swiper:

// ========== Login Logic ==========
const openLoginBtn = document.getElementById('openLogin');
const closeLoginBtn = document.getElementById('closeLogin');
const loginOverlay = document.getElementById('loginOverlay');
const loginForm = document.getElementById('loginForm');
const loginError = document.getElementById('loginError');

openLoginBtn.addEventListener('click', () => {
  loginOverlay.classList.add('active');
});

closeLoginBtn.addEventListener('click', () => {
  loginOverlay.classList.remove('active');
  loginError.classList.remove('visible');
  loginForm.reset();
});

loginOverlay.addEventListener('click', (e) => {
  if (e.target === loginOverlay) {
    loginOverlay.classList.remove('active');
    loginError.classList.remove('visible');
    loginForm.reset();
  }
});

loginForm.addEventListener('submit', (e) => {
  e.preventDefault();
  const user = document.getElementById('loginUser').value;
  const pass = document.getElementById('loginPass').value;

  if (user === 'admin' && pass === '123') {
    window.location.href = 'admin/home.html';
  } else {
    loginError.classList.add('visible');
  }
});

========================================================================
SISTEMA DE POSTS (CARDS DINAMICOS)
========================================================================

Os cards do carrossel em index.html serao posts criados e gerenciados
pela area restrita (admin). Os dados sao armazenados no localStorage
do navegador.


1. ARQUIVOS ENVOLVIDOS
------------------------
- estilos/style.css    -> estilos do card (ja existente)
- estilos/posts.css    -> estilos do card de post e galeria
- js/script.js         -> logica do Swiper + Login (ja existente)
- js/posts.js          -> CRUD de posts via localStorage
- index.html           -> carrega posts dinamicamente no carrossel
- admin/home.html      -> formulario para criar/editar/deletar posts


2. ESTRUTURA DE UM POST NO localStorage
------------------------------------------
Chave: "sci_posts"
Valor: array de objetos JSON

Exemplo:
[
  {
    "id": 1,
    "title": "UNIVERSE OF UI",
    "stat1num": "2626",
    "stat1label": "UI elements",
    "stat2num": "100%",
    "stat2label": "Free for use",
    "stat3num": "38,631",
    "stat3label": "Contributers",
    "icon": "code"
  }
]

Icones disponiveis: code, star, heart, bolt, gem, fire


3. COMO FUNCIONA NO index.html
---------------------------------
a) Ao carregar a pagina, js/posts.js busca "sci_posts" no localStorage
b) Se nao existir, cria posts padrao (os 4 cards atuais)
c) Renderiza cada post como um .swiper-slide > .card
d) O Swiper e reinicializado apos renderizar os slides


4. COMO FUNCIONA NO admin/home.html
--------------------------------------
a) Ao carregar, busca "sci_posts" no localStorage
b) Lista todos os posts com botoes de Editar e Excluir
c) Formulario de criacao com campos:
   - Titulo do post
   - 3 estatisticas (numero + label)
   - Icone (select com opcoes)
d) Botao "Criar Post" adiciona ao localStorage e atualiza a lista
e) Botao "Excluir" remove pelo id
f) Botao "Editar" preenche o formulario para atualizar


5. FLUXO RESUMIDO
-------------------
a) Admin loga com admin/123 -> vai para admin/home.html
b) Cria posts com titulo, estatisticas e icone
c) Posts ficam salvos no localStorage
d) index.html carrega os posts e mostra no carrossel
e) Qualquer pessoa pode ver os posts no carrossel (sem login)
f) Admin pode editar/excluir posts pela area restrita
